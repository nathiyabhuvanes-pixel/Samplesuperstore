# Sample Superstore Dataset Analysis

##  Project Title

**Sample Superstore Data Analysis Using Python Libraries**

---

##  Objective

The main objective of this project is to analyze the *Sample Superstore dataset* using Python libraries and understand sales and profit performance through basic data analysis and visualization techniques.

---

##  Libraries Used

The following Python libraries were used in this project:

* **Pandas** – Data loading and manipulation
* **NumPy** – Numerical calculations
* **Matplotlib** – Data visualization (bar charts)
* **Seaborn** – Advanced visualizations (scatter plots)
* **Scikit-learn** – Data splitting for machine learning
* **SciPy** – Statistical analysis

---

##  Dataset Information

* **Dataset Name:** Sample Superstore
* **File Format:** CSV
* **Description:**
  This dataset contains sales data including categories, regions, profits, and customer-related information used for analysis.

---

##  Tasks Performed

1. Imported all required Python libraries
2. Loaded the dataset using Pandas
3. Displayed the first five rows of the dataset
4. Checked dataset structure and information
5. Identified missing values in the dataset
6. Calculated average sales using NumPy
7. Analyzed total sales by category using Pandas
8. Created a bar chart using Matplotlib
9. Created a scatter plot using Seaborn
10. Split the dataset into training and testing sets using Scikit-learn
11. Calculated mean sales using SciPy

---

##  Output

* Successfully loaded and explored the dataset
* Generated statistical insights such as average and mean sales
* Visualized sales data using bar charts and scatter plots
* Performed basic machine learning data preparation
